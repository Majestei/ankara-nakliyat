# Search Intent & Content Protocol

## One dominant purpose

Every important landing page should have a clear dominant searcher task.

## Research

When doing competitor research:
- inspect patterns across multiple relevant results
- distinguish informational vs commercial/local intent
- identify useful topics/features competitors cover
- never copy their text

## Page value test

Ask:
"If the city/service keywords were removed, would this page still contain meaningful unique value?"

If no, the page is at risk of being thin/templated.

## Titles/H1s

Be descriptive and natural.
Avoid keyword chains.
Avoid unverifiable superlatives.

## Internal linking

Use links to connect genuine topic/service/location relationships.
Do not create mass exact-match footer links solely for ranking.

## Project workflow

Use site-specific gsc:report as described in .agents/INTEGRATION.md. Read separate propertyTotals, page, query and page-query datasets. Anonymized queries mean these totals differ. Compare equal periods and validate intent before labeling cannibalization.
